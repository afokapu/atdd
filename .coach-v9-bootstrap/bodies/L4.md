## Scope

### In Scope

L4 implements four observer rules from spec §8.3 by absorbing four functions from `commands/babysit.py` verbatim into observer-rule modules per spec §0.2.

- **`13-bash-auto-approve`** (absorbs `classify_prompt`, `_classify_bash_command`, `_load_bash_patterns`, `BashPattern`):
  - Reads `orchestration.convention.yaml::babysit.bash_auto_approve_patterns.rules` and `bash_deny_patterns.rules` via the absorbed `_load_bash_patterns`.
  - On match against an approve pattern: auto-approves the prompt.
  - On match against a deny pattern: escalates.
  - The bash-patterns file is unchanged.
- **`14-canonical-naming-drift`** (absorbs `correct_naming_drift`):
  - On each tick, compares multiplexer surface name to canonical via `is_canonical_name`.
  - On drift: calls `correct_naming_drift` to re-apply the canonical name within one tick.
  - Logs `coach.orchestration.canonical-session-name`.
- **`15-layout-drift`** (absorbs `correct_layout_drift`):
  - On each tick, compares surface count + arrangement to `target_grid_label` from `session_naming.py`.
  - On drift: calls `correct_layout_drift` to re-apply the canonical layout.
  - Logs `coach.orchestration.layout-conformance`.
- **`16-smoke-skip`** (absorbs `detect_violation` `--status REFACTOR` clause):
  - Detects phase transition from GREEN to REFACTOR without an intervening SMOKE.
  - Same screen patterns that fire today's `detect_violation` SMOKE-skip flag fire this rule.

Each rule is co-located at `.atdd/observer/rules/<NN>-<slug>.yaml` with a unit test that asserts behavior parity with the babysit equivalent.

The `tester` archetype is on this issue (in addition to `coach`) because the parity assertion across four absorbed functions exercises the test substrate's parity-fixture pattern (mirrors the discipline of the orchestrate parity tests in #K5).

Rule-IDs introduced: `13-bash-auto-approve`, `14-canonical-naming-drift`, `15-layout-drift`, `16-smoke-skip`. Schemas: `correction.schema.json`. Existing rule-IDs reused: `coach.orchestration.canonical-session-name`, `coach.orchestration.layout-conformance`.

### Out of Scope

- Other observer rules (#L1 skeleton, #L2 basic, #L3 token, #L5 substrate-aware).
- Decommissioning `atdd babysit` — #P6 owns it, gated on the #L8 parity suite.
- Modifying `orchestration.convention.yaml::babysit.bash_auto_approve_patterns.rules` or the underlying canonical-name / layout machinery — this issue absorbs verbatim.
- `atdd observer aggregate-approve` — #L7 absorbs `aggregate_approve` separately. Rule 13 covers per-prompt classification; #L7 covers cross-surface batch action.

## Context

### Problem Statement

| Aspect | Current | Target | Issue |
|--------|---------|--------|-------|
| Bash auto-approval | `classify_prompt` runs inside babysit's polling loop, classifies tool prompts against `bash_auto_approve_patterns.rules` and `bash_deny_patterns.rules`, auto-approves matches | Same logic in observer rule 13, evaluated per-event in the L1 loop, with the patterns file unchanged | Without absorption, decommissioning babysit deletes the auto-approve capability and operators must approve safe prompts manually |
| Canonical-naming drift correction | `correct_naming_drift` re-applies canonical names from `session_naming.py::compute_canonical_name` when a surface drifts | Same logic in observer rule 14, fired per tick, logging `coach.orchestration.canonical-session-name` | Drift correction is one of the lived guardrails for multi-surface coach runs; it must move with the decommissioning |
| Layout drift correction | `correct_layout_drift` re-applies the canonical grid arrangement when surface count or topology drifts | Same logic in observer rule 15, fired per tick, logging `coach.orchestration.layout-conformance` | Same rationale as rule 14 — operator-visible guardrail that cannot regress |
| SMOKE-skip detection | `detect_violation` flags `--status REFACTOR` when no SMOKE preceded it | Observer rule 16 fires on the same screen patterns | Without it, the GREEN→REFACTOR shortcut goes undetected; with it, the §6.4 phase-ordering contract is enforced in observer-time |

### User Impact

The "user" is every operator running a multi-surface coach session and every coach-orchestrated agent. Per spec §0.2, the absorbed functions ship in babysit today and provide real, exercised behavior. #L4 lifts them onto the L1 substrate without behavior change, so #P6 (babysit decommissioning) does not regress operator experience.

The four behaviors reflect four lived failure modes:
1. Operators were drowning in auto-approvable tool prompts (rule 13).
2. Multi-surface session names drifted under multiplexer churn (rule 14).
3. Multi-surface grid arrangements drifted under multiplexer churn (rule 15).
4. Agents shortcut from GREEN to REFACTOR, bypassing SMOKE — exactly the failure mode that motivates spec §4.1's phase enum (rule 16).

After L4 lands, all four behaviors run on the L1 evaluation loop instead of the babysit polling loop — the agent and operator experience is unchanged, the substrate is the new one.

### Root Cause

Each of the four absorbed functions encodes a real, lived correction loop that the babysit author observed in production. Coach v9 deliberately replaces babysit's polling-and-fixed-pattern model (per spec §1, motivation 1) but cannot afford to drop the patterns themselves — they are operationally important. The canonical absorption pattern (§0.2) is "preserve the function bodies; change the caller." That is what #L4 does.

## Acceptance

- `acc:observe-and-correct:M003-UNIT-001-rule-13-bash-auto-approve`: Rule `13-bash-auto-approve` reads `orchestration.convention.yaml::babysit.bash_auto_approve_patterns.rules` and `bash_deny_patterns.rules` via the absorbed `_load_bash_patterns`/`BashPattern`; a known-safe prompt is auto-approved without operator intervention; a deny-pattern prompt triggers an escalation; the bash-patterns file is unchanged.
- `acc:observe-and-correct:M003-UNIT-002-rule-14-naming-drift`: Rule `14-canonical-naming-drift` detects a drifted multiplexer surface name via `is_canonical_name`, calls `correct_naming_drift`, re-applies the canonical name within one tick, and logs `coach.orchestration.canonical-session-name`; surfaces already at canonical names do not fire.
- `acc:observe-and-correct:M003-UNIT-003-rule-15-layout-drift`: Rule `15-layout-drift` detects surface count or arrangement that no longer matches `target_grid_label`, calls `correct_layout_drift`, re-applies the canonical layout, and logs `coach.orchestration.layout-conformance`; conforming arrangements do not fire.
- `acc:observe-and-correct:M003-UNIT-004-rule-16-smoke-skip`: Rule `16-smoke-skip` flags a phase transition from GREEN to REFACTOR without an intervening SMOKE — at parity with babysit's `detect_violation` `--status REFACTOR` clause; a trajectory GREEN → SMOKE → REFACTOR does NOT fire.
